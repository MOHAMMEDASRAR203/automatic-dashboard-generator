# 🤖 Automatic Dashboard Generator

An automated data analytics dashboard built using Python and Streamlit.

The application allows users to upload Excel or CSV files and automatically analyzes the dataset, generates KPIs, creates visualizations, identifies data quality issues, and provides useful analytical insights.

---

## 📌 Project Overview

Data analysis often requires several manual steps such as cleaning data, identifying important columns, calculating KPIs, creating charts, and finding business insights.

This project automates many of these initial data-analysis tasks.

Users simply upload their dataset, and the application analyzes the data and generates an interactive dashboard automatically.
